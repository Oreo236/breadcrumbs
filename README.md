# breadcrumbs

Every adventure leaves a trail.

A social navigation app: describe your time/budget/interests, get a generated route of real places, navigate it with friends, drop photo "Breadcrumbs" along the way, and keep the finished trip as a shared album on your memory map.

See [CLAUDE.md](./CLAUDE.md) for the full build brief, architecture, data model, and milestone plan.

## Getting started

```bash
npm install
cp .env.example .env   # fill in Supabase URL + anon key
npx expo start
```

Scan the QR code with Expo Go (iOS/Android) to run on a device.
